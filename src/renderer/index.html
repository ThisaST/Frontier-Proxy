Skills

Frontier reads the skills your CLIs already discover (~/.claude/skills, .agents/skills and the other folders below) and never writes to those folders. Turning a skill off only changes what Frontier tells each agent to use.

Turning a skill off is enforced for Claude Code and OpenCode. For Copilot and Codex it is a best-effort instruction in the prompt, not a guarantee.

Scanned folders

Where Frontier looked for this project, and which CLIs find each folder on their own.

Check isolated branches

After an agent finishes on its own branch (a split-and-delegate subtask, a comparison lane, or a workspace writing turn), Frontier runs this project's own checks against that worktree and reports the result in Review. Nothing is ever merged automatically.

Only a run that committed changes is checked. A failing check never fails the agent's run.

Commands

Leave blank to detect them: Frontier reads package.json scripts (typecheck, lint, test), then a Makefile, Cargo.toml or go.mod. Custom commands replace detection entirely, and run with no shell, in the worktree only. A branch with no checks is reported as “No checks detected”, never as passing.

A check that runs longer is stopped and reported as timed out.
