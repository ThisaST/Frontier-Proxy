GETTING STARTED

01Hosted coding agents

Codex, Claude Code, GitHub Copilot, and OpenCode are included. Install and sign in to each CLI (opencode auth login for OpenCode), then choose Check agents.

02Local models

Start Ollama, pull the configured model, then enable Codex + Ollama or direct Ollama.

03Other agent CLIs

Choose Add CLI, enter its executable and arguments, save, and confirm its status becomes Ready.
